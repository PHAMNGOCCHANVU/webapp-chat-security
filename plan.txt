## 📊 MAPPING API ENDPOINTS

### Authentication Endpoints (Backend ✅)
```
POST   /api/v1/auth/register        ← Frontend: auth.js
POST   /api/v1/auth/login           ← Frontend: auth.js
POST   /api/v1/auth/logout          ← Frontend: auth.js
GET    /api/v1/auth/profile         ← Frontend: app.js, chat.js (sửa từ /auth/me)
PUT    /api/v1/auth/profile         ← Frontend: app.js (update profile)
POST   /api/v1/auth/change-password ← Frontend: (nếu có forgot-password.html)
```

### Chat Endpoints (Backend ✅)
```
GET    /api/v1/rooms                ← Frontend: app.js (listRooms)
POST   /api/v1/rooms                ← Frontend: app.js (createRoom)
GET    /api/v1/rooms/:id            ← Frontend: app.js (getRoomDetails)
GET    /api/v1/rooms/:id/messages   ← Frontend: app.js, chat.js (getMessages)
POST   /api/v1/rooms/:id/members    ← Frontend: app.js (addMember)
DELETE /api/v1/rooms/:id/members/:userId ← Frontend: app.js (removeMember)
```

### Socket.IO Events (Backend ✅)
```
join-room              ← Frontend: app.js, chat.js (sửa roomId → conversationId)
leave-room             ← Frontend: app.js, chat.js
send-message           ← Frontend: app.js, chat.js
typing                 ← Frontend: app.js, chat.js (nếu có)
get-message-history    ← Frontend: app.js, chat.js
get-active-users       ← Frontend: app.js, chat.js (nếu có)
```

### Admin Endpoints (Backend ✅)
```
GET    /api/v1/admin/audit-logs    ← Frontend: admin.js
GET    /api/v1/admin/users         ← Frontend: admin.html (nếu có)
PATCH  /api/v1/admin/users/:id/role ← Frontend: admin.html (nếu có)
```
