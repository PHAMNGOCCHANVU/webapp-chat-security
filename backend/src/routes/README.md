# Ghi chú thư mục routes

Mục tiêu:

- Định nghĩa endpoint API v1.
- Áp middleware theo từng nhóm route.

Hiện trạng:

- /api/v1/auth: đăng ký, đăng nhập, refresh access token, đăng xuất, profile, đổi mật khẩu.
- /api/v1/rooms: thao tác phòng chat và tin nhắn.
- /api/v1/admin: user management và audit logs.
